## 実行した自動テスト

実行場所：この回答を作成するLinuxコンテナ。Python 3.13.5の標準unittest。macOSの実機をエミュレートしたものではありません。

```bash
python3 -m unittest discover -s tests -v
```

**102テスト、失敗0、エラー0。** Python 3.11文法でのAST解析とbash構文チェックにも合格しました。Python 3.11での実行試験を代替するものではありません。実行ログは[TEST_RESULTS.txt](TEST_RESULTS.txt)に保存しています。ログ中の`fixture.tail123.ts.net`等は模擬データであり、実際のMac miniのURLではありません。

主な検査は、不正なモデル/ポート/URLの拒否、秘密情報をシェルへ展開しないこと、保存設定の一致、初期登録の未完了時公開拒否、他人の経路削除拒否、既存443経路保持、バックアップ改変検出、本番を変更しない隔離コピーです。

ローカルHTTP試験ではこのパッケージが期待するAPI形式を模擬しています。**本物のOpen WebUIとのAPI互換性を証明する試験ではありません。** 実際の採用版のAPIが異なれば安全側で停止し、上流に合わせた修正と実機再試験が必要です。

## 仕様からの実装上の補足

- 初回の`WEBUI_URL`だけ最終HTTPS URLで初期化します。初回のCORS/Cookie/実アクセスはloopback HTTPです。SSOは使いません。
- `ENABLE_PERSISTENT_CONFIG=true`を本番で維持します。既知の設定キーを公式APIで照合し、環境変数だけの確認にはしません。
- 1会話5ファイルは運用ルールです。上流の件数設定は一度のアップロード上限であり、会話内の累積を独自実装しません。
- バックアップの形式は、見えるフォルダとハッシュ一覧です。自動的な本番上書き復元ではなく、隔離コピーを起動する試験までを実装しました。
- `requirements.lock`と正確なPythonパッチ版は実機導入時に記録します。Open WebUIの候補版以外の「Macで動作確認済み版」はまだありません。
- optionalな設定変数が採用版にない場合は記録します。必須キーが不明なら導入/公開を止めます。ログに警告なく未知の機能が全部禁止されたとは判断しません。

## 0.1.1 実機preflight反映

- Mac mini: Apple M4 Pro / 64GB / macOS 27.0 / arm64 を確認。
- 8443番は既存Tailscale Serve（127.0.0.1:4317へのProxy）が使用中のため、本プロジェクトは9443番を使う。
- 11434番には既存Ollamaがいるため、既存Ollama再利用モードを追加。
- 既存Ollama再利用時は本ツールが起動・停止・LaunchAgent所有を行わない。
- 既存Ollamaの待受がIPv4 loopback限定でなければ導入を拒否する。
- 443番および既存8443番のServe経路は変更対象外。
